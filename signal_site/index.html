METHODOLOGY

How the signal is produced

1 · Observe

Daily readings from NOAA sea-surface temperature indices, satellite chlorophyll concentration, and subsea chemical plume monitoring.

2 · Measure

A grid-search optimizer sweeps smoothing windows and lead times to find the lag at which each ocean variable most consistently precedes price.

3 · Validate

Signals are tested with Dickey–Fuller stationarity and Granger causality tests before any setup is published. Noise is never traded.

4 · Replay

The engine is replayed out-of-sample over the prior five years to build an honest track record — the same output a subscriber would have received.
